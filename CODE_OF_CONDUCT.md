# Code of Conduct

KakeFlow contributors must communicate respectfully, give actionable technical feedback and avoid harassment, discrimination or disclosure of another person's private information.

Project discussions should stay focused on improving KakeFlow. Financial documents, credentials and personal identifiers must never be posted in public issues or pull requests.

Maintainers may edit or remove content, reject contributions or restrict participation when behavior threatens the safety, privacy or constructive operation of the community. Serious conduct concerns should be reported privately through the maintainer's GitHub profile. Vulnerabilities must use the canonical repository's [private GitHub Security Advisory form](https://github.com/thangldw/kakeflow/security/advisories/new).

Repository-specific contribution and data-handling rules are defined in [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/SECURITY.md](docs/SECURITY.md).
