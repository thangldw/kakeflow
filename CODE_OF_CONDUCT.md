# Code of Conduct

KakeFlow contributors must communicate respectfully, give actionable technical feedback and avoid harassment, discrimination or disclosure of another person's private information.

Project discussions should stay focused on improving KakeFlow. Financial documents, credentials and personal identifiers must never be posted in public issues or pull requests.

Maintainers may edit or remove content, reject contributions or restrict participation when behavior threatens the safety, privacy or constructive operation of the community. Serious concerns should be reported privately through the maintainer's GitHub profile or a private GitHub Security Advisory when the concern involves a vulnerability.
