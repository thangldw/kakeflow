# KakeFlow synthetic receipt-to-provenance demo

This public demo is generated by `npm run capture:pwa:demo`. It uses only the repository's anonymized synthetic receipt fixture, creates no online account, contacts no financial institution, and runs OCR, approval, posting, offline recovery, export, and restore locally in the browser.

| Time | Evidence shown | Claim boundary |
| --- | --- | --- |
| 00:00-00:11 | Account-free encrypted vault creation and minimum household ledger setup | The passphrase is entered locally; no cloud account is created. |
| 00:11-00:29 | Synthetic receipt selection, real PP-OCRv5 result, original image, and parsed candidate | OCR is on-device. Extracted fields remain a candidate. |
| 00:29-00:41 | Explicit approval, debit/credit equality, and posted canonical hash | Nothing posts before the checkbox decision; the posting is balanced. |
| 00:41-00:57 | Ledger row and source-to-candidate-to-posting provenance | The visible posting links back to encrypted source evidence. |
| 00:57-01:09 | Vault lock, offline service-worker reload, unlock, and restored read model | The committed local ledger remains usable without network access. |
| 01:09-01:25 | Authenticated encrypted archive download, full validation, atomic restore, and ledger readback | Restore activates a new vault only after validation; native backup compatibility is not claimed. |

The reviewed artifact is 85.320 seconds at 1440x900. `ffprobe` enforces the 85-95 second duration gate, the capture script transcodes to H.264/yuv420p, and the adjacent `.sha256` file identifies the reviewed artifact.
