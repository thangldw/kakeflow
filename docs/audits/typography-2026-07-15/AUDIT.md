# KakeFlow typography audit — 2026-07-15

The audit established a Japanese-first system sans-serif stack, tabular financial numerals, restrained monospace use for evidence, and a compact but readable desktop scale.

## Accepted rules

- No user-facing text below 10px.
- Primary financial values use strong weight and full text contrast.
- Amounts align with tabular numerals.
- Hashes, IDs, source rows, and dense dates use monospace.
- Dark theme preserves hierarchy and semantic meaning.
- Marketing/project-page typography remains compatible without importing a competing application font system.

Screenshots in this directory record the before/after pass. Current exact tokens are maintained in the [v2 handoff](../../../design_handoff_kakeflow_v2/README.md).
