# SBI Securities import-flow audit

This historical audit verified that SBI trade-history entry is discoverable from Home/Import, uses the dedicated adapter, requires an explicit securities account, preserves source fields, displays row issues, and saves only after an explicit investment action.

It also confirmed that brokerage events remain separate from household expense candidates. Current source semantics are documented in [SBI Securities import](../../SBI_SECURITIES_IMPORT.md).

The screenshots are dated UI evidence and may not match the current shell pixel-for-pixel.
