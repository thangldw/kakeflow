# Dashboard data-quality audit

Historical review of Home and card-settlement disclosures.

## Findings

- Dashboard metrics required an adjacent source-backed freshness and pending/failure summary.
- Card coverage needed explicit mapped bank, due-date, confirmed-payment, and missing-data states.
- “Confirmed data reflected” could not imply universal account completeness.
- Actions needed to route users to Import or Cards without changing financial facts.

The accepted contract is now documented in [Dashboard data quality](../../DASHBOARD_DATA_QUALITY.md) and [Card settlement coverage](../../CARD_SETTLEMENT_COVERAGE.md). Screenshots here remain dated evidence.
