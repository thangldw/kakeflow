# KakeFlow social assets

Deterministic exports for the KakeFlow v1.1.1 LinkedIn announcement.

- `kakeflow-v1.1.1-linkedin-{vi,en,ja}.jpg`: 1200 × 627 LinkedIn landscape cards.
- `kakeflow-v1.1.1-square-{vi,en,ja}.jpg`: 1080 × 1080 square cards.

The cards use KakeFlow's existing landing-page palette and real application screenshots from `docs/assets/demo`. All visible copy is rendered from `docs/social/social.js`; no generated claims or synthetic product UI are used.
