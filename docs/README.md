Documentation rules:

- Treat the source code and executable tests as authoritative when prose differs.
- Update Japanese, English and Vietnamese user-facing claims together.
- Use Mermaid source for maintained diagrams; do not commit generated diagram screenshots.
- Use only synthetic financial examples. Never commit personal receipts, statements, account numbers or local databases.
- Keep historical release notes and compatibility code when they are required to install, restore or migrate supported data.
