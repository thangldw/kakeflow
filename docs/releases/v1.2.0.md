# KakeFlow v1.2.0

KakeFlow v1.2.0 adds signed application updates, repeatable OCR regression coverage and a refreshed public project experience while keeping financial processing local-first.

[Download v1.2.0](https://github.com/thangldw/kakeflow/releases/tag/v1.2.0) · [Source code](https://github.com/thangldw/kakeflow) · [Product website](https://thangldw.github.io/kakeflow/)

## Highlights

- Signed Tauri updater channel with startup checks and a manual control in Settings.
- PP-OCRv5 regression fixtures covering Japanese receipt dates, totals, taxes and item prices.
- Japanese, English and Vietnamese landing page with real product captures and a synthetic end-to-end household use case.
- Optional Support my work dialog through GitHub Sponsors and MB Bank VietQR.
- GitHub quality checks, dependency updates, contribution guidance and privacy-aware issue templates.

## Installation

Download `KakeFlow_1.2.0_aarch64.dmg` for Apple Silicon Macs. This community build is ad-hoc signed and is not Apple-notarized. macOS may require opening KakeFlow through Finder's **Open** action or approving it under **System Settings → Privacy & Security**.

Existing v1.1.1 installations require this one manual upgrade. Starting with v1.2.0, KakeFlow can verify and install signed updates from the stable update channel.

The product website is maintained from `main/docs` and may receive documentation or demo-media improvements independently of the immutable v1.2.0 desktop artifacts.

## Verification

Release QA passed 746 frontend tests and 643 Rust tests, together with the production build, Rust format/clippy, OCR resource checks, packaged application/DMG smoke tests, PP-OCRv5 browser regression and updater manifest contracts. The published release includes SHA-256 checksums and a signed updater archive. KakeFlow does not send receipt images to Gemini or another hosted AI service.
