# KakeFlow v1.3.0

Release candidate refreshed 2026-10-07; publication requires verified signed artifacts.

## What changed

- Added a read-only Connector Control Center for native source inventory, health and refresh operations.
- Made connector account bindings an explicit posting-authorization boundary, with version and generation fencing against stale or ABA updates.
- Added durable refresh batches, per-source cursors and backoff, fail-closed recovery, and redacted operational summaries.
- Hardened the isolated macOS ARM64 release path with canonical physical paths, atomic locks, source/resource identity digests, and packaged artifact verification.
- Removed two test-only CodeQL data flows at their source and recorded the generated Tauri macro finding separately as a false-positive candidate pending exact-head analysis.

## Install

**Manual upgrade required from every earlier desktop version, including v1.2.1.** The previous updater private key was lost. v1.3.0 embeds a new public key, so an earlier installation cannot authenticate this release through its updater. This is a recovery rotation, not evidence of a key compromise.

Before upgrading, export a backup using the existing application and keep its backup password. Quit KakeFlow, download the official v1.3.0 DMG, and replace only `KakeFlow.app` in Applications. Do not delete application data or Keychain entries. The bundle identifier remains `app.kakeflow.desktop`; this key rotation does not change database paths, schemas or credential identifiers. Validate the upgrade on a disposable profile before claiming data-preservation evidence.

Once manually installed, v1.3.0 can authenticate future updates signed by the new key. It cannot retroactively repair automatic updates in older installations. Public key ID: `348EFBA1FBABBCD5` (previous: `4BDDD1FCDA53215A`).

- PWA: [thangldw.github.io/kakeflow/app](https://thangldw.github.io/kakeflow/app/)
- macOS Apple Silicon: download `KakeFlow_1.3.0_aarch64.dmg` from the [canonical GitHub release](https://github.com/thangldw/kakeflow/releases/tag/v1.3.0).
- Verify the downloaded file against `SHA256SUMS.txt` before opening it.

The macOS community binary is ad-hoc signed and not notarized. The account-free PWA is the supported no-Gatekeeper path.

## Evidence and boundaries

- Frontend, release-contract, Rust, PWA, Poppler and CodeQL gates must pass for the exact release commit before publication.
- `node scripts/verify-v121-migration.mjs` (Node with `node:sqlite`, full checkout including tag `v1.2.1`) verifies the unchanged 69 historical migrations, applies migrations 70–72, preserves synthetic household/account rows, and checks database integrity and foreign keys. It also compares the bundle identifier and key-store source with v1.2.1. This is SQL-level evidence, not SQLCipher, Keychain, document-vault or installed-upgrade proof; that acceptance check remains required.
- Connector tests use synthetic adapters and records. This release does not claim a production bank pilot, direct bank aggregation or Money Forward parity.
- The PWA intentionally has no desktop provider clients, connector credentials or native backup compatibility.
- Updated rustls to 0.23.45 and backported the upstream GLib VariantStrIter mutable output-pointer fix while preserving the GTK ABI. The GLib backport has native regression tests and explicit source provenance.
- Build-time proc-macro libraries retain their symbols to avoid the macOS 27 loader alignment bug tracked in [rust-lang/rust#157750](https://github.com/rust-lang/rust/issues/157750). This applies to host build tools only; the application still uses compile-time path remapping and packaged privacy checks.
- Poppler provides automated visual QA artifacts, not human visual approval.
