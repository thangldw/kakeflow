CARD PAYMENT RULE

カード利用は一度だけ支出にする。

購入時に費用とカード負債を記録し、後日の銀行引落は負債の返済として扱います。

  1. 7/3カードで買い物支出 ¥5,400
  2. 7/27銀行から引落負債 −¥5,400
  3. 結果支出は一件二重計上なし

CURRENT LIMITS

現在の制約

  • GitHub 配布の macOS DMG は ad-hoc 署名・notarization なし、Windows installer は unsigned
  • すべての金融機関や statement 形式を網羅していない
  • 金融データは user-provided file と user-controlled inbox のみ。銀行・カード等への direct API 接続は行わない
  • OCR・自動分類の低 confidence 候補は人の確認が必要
  • 家計データの完全性は、取り込んだ原本の範囲に依存
  • EML は表形式添付1件のみ。Gmail direct connector は test user 限定で、provider qualification 前
