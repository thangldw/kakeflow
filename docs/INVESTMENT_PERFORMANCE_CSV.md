# Annual Investment Performance CSV

KakeFlow can export the annual Investment Performance report as a UTF-8 BOM CSV generated by the native desktop process. The exporter runs the same validated `InvestmentPerformanceRequest` and FIFO query as the visible annual report, so CSV, XLSX, and PDF share one calculation boundary instead of maintaining separate performance models.

## Scope and accounting semantics

The desktop action sends the selected calendar year's inclusive `dateFrom` and `dateTo`, the current `householdId`, and no account filter. The native boundary also accepts an optional securities `accountId`, but it must belong to the same household. Missing, malformed, reversed, or non-calendar-year boundaries fail instead of being silently corrected.

Earlier acquisitions may be scanned to establish FIFO cost basis for a sale inside the selected year. Period totals and dated allocations are still restricted to the requested annual range. Diagnostic event IDs without a date in the report DTO are exported as exceptions, not relabeled as annual transactions.

Every amount remains in its event's native currency. KakeFlow does not add unlike currencies or invent a conversion rate. The export is not a holdings, current valuation, unrealized P&L, asset allocation, ROI, TWR, IRR, or forecast report.

## Flat record grains

The file has one fixed 36-column header and uses `record_type` to make each row's grain explicit:

- `CURRENCY_TOTAL` — buy gross, sell gross, realized P&L, dividends, fees, and taxes for one native currency;
- `REALIZED_ALLOCATION` — a FIFO buy-to-sell allocation with event IDs, dates, quantities, amounts, and both source document/row references;
- `CORPORATE_ACTION_ALLOCATION` — allocated spin-off, split, merger, or other supported action facts, including source-buy lineage and explicit conversion fields when the validated DTO provides them;
- `UNCOVERED_SALE` — sale quantity for which FIFO cost basis is unavailable;
- `SKIPPED_EVENT` — an event excluded from the FIFO calculation;
- `UNALLOCATED_CORPORATE_ACTION` — a corporate-action event without an allocation row; and
- `DISCLOSURE` — three fixed statements describing currency separation, exception completeness, and metrics intentionally absent from this report.

Household, account scope, annual range, `FIFO`, and the native-currency policy repeat on every row so a filtered subset retains its context. Nullable realized P&L uses `AVAILABLE` or `NOT_PROVIDED`; missing source values remain blank and are never changed to zero or fabricated provenance.

## File and save boundary

The native process creates RFC-style quoted CSV with CRLF records and a UTF-8 BOM for Japanese spreadsheet compatibility. It queries, validates, generates, opens the native save dialog, and writes the file; CSV content does not cross WebView IPC. The UI receives only filename, row count, byte size, or cancellation.

Generation is bounded to 25,003 data rows and 16 MiB. The exporter also reuses the stricter annual FIFO report validation used by the XLSX exporter. Invalid scope, annual boundaries, non-FIFO data, malformed dates/currencies/provenance, non-finite values, impossible corporate-action source requirements, and output limits fail closed. Cancellation writes nothing and leaves the loaded report unchanged.
